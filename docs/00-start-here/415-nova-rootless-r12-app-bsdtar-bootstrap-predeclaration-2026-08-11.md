## Question

R11 proved the rootless guest can download a Steam CDN payload, but its direct
Android toybox `tar` path rejected Holo archive symlink/metadata entries. The
successful retry used `/data/local/tmp/nova-runtimes/.../rootfs/usr/bin/bsdtar`
as a read-only bootstrap, which is not acceptable as the sole clean-device
rootless provisioner.

The new APK build bundles an explicit ARM64 Holo `bsdtar`/glibc DT_NEEDED
closure and copies it to app-private launcher assets. R12 tests only that
bootstrap boundary: a fresh APK must materialize the bootstrap, and the
rootless archive helper must extract the pinned Holo archive using that
app-owned bootstrap without reading the rooted rollback image.

R12 does not launch Steam, run the Steam updater, copy Steam data, authenticate,
patch SteamUI, run Proton, or exercise Gamescope/AHardwareBuffer.
